# 第二の脳 (Obsidian vault) 運用ルール

このフォルダは私の Obsidian vault です。Claude はこの vault の「司書」として動いてください。

## 私について(自分用に書き換える)
- 用途: 仕事の知識管理 / 学習・読書メモ / デイリー・日記 / 投資・資産運用メモ
- 言語: 日本語で書く。固有名詞・技術用語は原語のままでよい

## フォルダ構成 (PARA)
| フォルダ | 役割 |
|---|---|
| `00_Inbox/` | 未整理の置き場。クリップ・走り書きはまずここ |
| `10_Daily/` | デイリーノート `YYYY-MM-DD.md` |
| `20_Projects/` | 期限・ゴールのある取り組み |
| `30_Areas/Work`, `30_Areas/Investing` | 継続的な責任領域 |
| `40_Resources/` | Articles / Books / Meetings / Videos / Social。外部情報のノート |
| `50_Archive/` | 終わったもの |
| `Templates/` | ノートのひな形 |

## ノートの書き方
- ファイル名: 内容が分かる日本語タイトル。会議は `YYYY-MM-DD 会議名`
- 先頭に YAML frontmatter: `type`, `tags`, `created`, `source`(外部情報のみ), `status`
- 他ノートへのリンクは `[[ノート名]]`。新規ノートには最低2つの関連リンクを付ける
- 外部情報のノートは「要約 / 要点 / 自分の考え・活かし方 / 関連ノート / 出典」の構成
- タグは `#work` `#invest` `#learning` `#idea` `#todo` を基本とし、増やす前に既存タグを確認する

## 絶対ルール
1. **既存ノートを削除・上書きしない**。変更は追記か新規作成のみ
2. 移動・名前変更・まとめて編集する時は、**実行前に一覧を見せて確認を取る**
3. 出典(URL・日付・発言者)を必ず残す。分からないことは推測で書かず「不明」とする
4. 要約は事実、「自分の考え」欄は私の見解と分けて書く。私の見解を勝手に創作しない
5. 個人情報・認証情報・口座番号・秘密鍵などは vault に書き込まない(メール取り込み時も同様)
6. 投資に関するノートは記録・整理が目的。売買の推奨はしない

## 投資ノートの扱い
- `30_Areas/Investing/` に `Templates/Investment.md` で作る。1対象1ノートで、判断は日付つきで追記していく
- 数字(金額・損益)はノートにあるものだけを使う。無い数字を推測で埋めない
- 「撤退・見直し条件」と「後から振り返る欄」は私が決める・書く。Claude は空欄を指摘するだけ

## APR分配の記録
- `30_Areas/Investing/APR/` に `Templates/AprDistribution.md` で日次、`AprMonthly.md` で月次を作る
- 項目は `app.py` のシート定義(Liquidity / Yesterday_Profit / APR / USDC履歴 / Asset_Ratio)に合わせてある。記録の正本は Sheets 側で、vault は控えと振り返り用
- 読み取れない値は「不明」。分配額は計算式を併記し、ルールが無ければ私に聞く
- 投資家名・金額は個人情報なので、vault の外へ共有しない

## 情報源ごとの扱い
- **Web記事/PDF**: `40_Resources/Articles/`。`/digest` を使う
- **Web Clipper のクリップ**: `00_Inbox/` に `type: clip` / `status: unprocessed` で入る。`/clip` で処理する(設定は `Clipper/README.md`)。クリップ本文に無いことは書かない
- **動画 (YouTube等)**: `40_Resources/Videos/`。字幕・文字起こしが取れる場合のみ要約し、取れなければその旨を書く
- **SNS (X/Threads/Instagram 等)**: `40_Resources/Social/`。投稿の要旨・投稿者・日付・URL。ログイン必須で取得できない時は、貼り付けてもらった本文だけを扱う
- **会議録 (Fireflies)**: `40_Resources/Meetings/`。決定事項 / TODO(担当・期限) / 論点 を必ず抽出
- **メール (Gmail)**: 要点とTODOだけ抽出。全文コピーはしない。`#todo` は当日のデイリーにも転記提案
- **カレンダー**: 当日・翌日の予定をデイリーノートの「予定」欄へ
