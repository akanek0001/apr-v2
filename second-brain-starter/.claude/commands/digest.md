---
description: URL(記事/動画/SNS)やPDFを要約し、既存知識と結びつけて保存する
argument-hint: <URL またはファイルパス>
---
対象: $ARGUMENTS

1. 内容を取得する。種別は URL から判定: 記事 → `40_Resources/Articles/`、動画 → `Videos/`、SNS → `Social/`、PDF → 内容に応じて `Articles/` か `Books/`
   - 動画は字幕・文字起こしが取れた時だけ要約。取れなければその旨を書き、要約を捏造しない
   - SNS などログインが必要で取得できない場合は、取得できなかったと伝え、本文の貼り付けを依頼する
2. `Templates/Resource.md` に沿ってノートを作る(要約 / 要点 / 出典は必須。「自分の考え」欄は空欄のまま残し、私に書かせる)
3. vault を検索し、関連ノートを2件以上 `[[ ]]` でリンクする
4. 作成したパスと、リンクした関連ノートを報告する
